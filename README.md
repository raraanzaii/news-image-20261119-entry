This entry is a single-page newspaper front page for Thursday 19 November
2026, rendered as one 1024×1024 PNG. A black masthead carries the paper's
name, "THE WORLD TODAY", in large white serif type, with the date picked
out in gold beneath it, and the whole page sits on a cream, newsprint-style
background.

The lead story dominates the top half of the page. Under a red "LEAD STORY"
tag, a purple-to-pink sunset fills the panel behind a silhouetted Vice City
skyline and leaning palm trees, and the headline "GTA VI IS HERE" is set in
huge block letters across it. The strapline underneath notes that, after a
13-year wait, Grand Theft Auto VI has begun its global rollout and gamers
are entering Vice City.

Below a "MORE TOP STORIES" divider, four smaller panels form a two-by-two
grid, each with its own colour scheme and a simple icon:

- **Politics** (navy panel, Capitol dome icon): "JEFFRIES SET TO LEAD THE
  HOUSE" — Democrat Hakeem Jeffries is set to become the first
  African-American Speaker of the US House.
- **Space** (near-black panel, probe-and-dish icon): "VOYAGER 1: ONE
  LIGHT-DAY FROM HOME" — NASA's probe, launched nearly 50 years ago, is now
  one light-day from Earth.
- **Europe** (EU blue panel with a circle of gold stars): "EU: €45 BILLION
  FOR UKRAINE" — the EU proposes a €45 billion loan to support Ukraine.
- **Weather** (dark teal panel, spiral storm icon): "CYCLONE AKVAN NEARS
  INDIA'S EAST COAST" — the storm is approaching the coast between
  Machilipatnam and Puri.

## Run it

```sh
python3 main.py
```

`main.py` copies the committed `entry.png` byte for byte into the output
directory — `/output` by default, or the directory named by the
`MAKEFUN_OUTPUT_DIR` environment variable when that is set. It uses only
the Python standard library and makes no network calls, so every run
produces exactly the same bytes.
